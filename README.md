# 🔥 Idioms & Slang Decoded (Repository 4 / Variety 4)

Automated video generator for **Popular American & British Idioms and Slang** in 9:16 vertical reels.

## 🌟 Key Features
- **Literal vs Actual Contrast**: Shows the funny literal interpretation vs what native speakers truly mean.
- **Historical Origin & Etymology**: Uncovers where the phrase originated (superstitions, historical battles, naval slang).
- **Natural Dialogue Usage**: Demonstrates real-life sentences learners can use immediately.
- **High Virality**: Educational and entertaining, prompting viewers to save and share.

## 🚀 How to Run
```bash
# 1. Generate idiom reel
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/idioms_slang_reel.mp4 output/run_XXXX/metadata.json
```

## 📱 Recommended Facebook Page Target
- **Page Concept**: *English Slang & Idioms Master / Speak Like A Native*
- **Target Audience**: Intermediate English learners wanting to sound informal, natural, and culturally savvy.
